Rule language guide

Fields: noise in dB (0-200, up to 3 decimals), hour (whole hour, 0-23), parkingMinutes (whole minutes, 0-10080).

Compare a field with a number using > >= < <= == !=. Combine comparisons with uppercase AND, OR and NOT. Field names are case-sensitive.

NOT binds first, then AND, then OR. Parentheses change grouping. For overnight hours use hour >= 22 OR hour < 6.

Rules support numeric comparisons only. They cannot run code, call functions or compare dates. Limit: 1,000 characters, 200 tokens, 20 nested groups/negations.
